# ai-video-inpaint-workflow
AIGC视频局部修复与逐帧跟踪脚本工作流

## 项目介绍
这套工作流实现了带逐帧目标跟踪的视频局部修复能力。
主要用于广告素材制作：去除视频内全部字幕、文字、花字和水印，也支持动态物体替换，例如车辆车牌替换。
仅修复被文字遮挡的局部区域，补全的背景自然连续，无马赛克、无涂抹、无模糊；保留原画清晰度、色彩、构图、产品细节与真实质感，其余内容保持不变，不重绘整张画面。
能够自动跟踪视频中的运动目标，跨帧生成连续蒙版，维持时序一致性，避免画面闪烁与马赛克瑕疵。

## 核心能力
1. 逐帧目标跟踪：自动追踪视频内移动物体，为每一帧生成蒙版
2. 视频局部重绘：仅修复蒙版划定区域，视频其余画面保持不变
3. 文字擦除：去除字幕、普通文字、花字、水印，无痕还原背景
4. 时序一致性优化：减少帧间画面闪烁，消除马赛克、涂抹类瑕疵
5. 批量处理：支持面向千川平台投放的短视频素材批量生成

## 技术栈
- Python
- SAM2 视频目标跟踪与蒙版传播
- 视频inpaint模型，实现局部画面修复
- ComfyUI工作流集成
- HyperFrames帧控制

## 使用场景
- 短视频广告去除字幕/文字/花字/水印
- 动态物体替换（车牌替换等场景）
- AIGC电商直播、带货广告素材制作

## 工作流程
1. 导入原始视频
2. 框选目标区域，使用SAM2跟踪目标物体，逐帧生成蒙版
3. 在蒙版区域执行局部修复
4. 后处理优化帧与帧之间画面一致性
5. 导出高清成品视频
